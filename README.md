# مدیریت بات‌های بله

یک پنل شخصی و مستقل برای اتصال چند بات بله، ساخت منو و جریان گفت‌وگو با فرم، دیدن کاربران هر بات و مرور رویدادها و گزارش پیام‌ها. این پروژه به n8n وابسته نیست و در نسخهٔ فعلی فقط یک حساب مدیر دارد.

## امکانات MVP

- افزودن چند بات با توکن جداگانه؛ توکن با `getMe` بررسی و در SQLite با AES-256-GCM رمزگذاری می‌شود.
- ثبت وب‌هوک جداگانه برای هر بات از طریق `setWebhook` و حذف آن هنگام پاک‌کردن بات.
- جریان‌های متنی با شروع `/start` یا عبارت دقیق، پیام و دکمه، منوی پاسخ، پیوند خارجی، ذخیرهٔ پاسخ کاربر و شرط «برابر است / شامل عبارت است».
- فهرست و پروفایل کاربران برای هر بات، همراه با اطلاعاتی که در Update بله آمده، پاسخ‌های ذخیره‌شده و مسیر زمانی.
- گزارش پیام‌های ورودی و نتیجهٔ ارسال پیام‌های خروجی، رویدادهای جریان و خطاهای API.
- نشست مدیر در کوکی HttpOnly و SameSite، بررسی مبدأ درخواست، محدودسازی تلاش ورود، جداسازی داده‌ها با شناسهٔ بات و رمزگذاری توکن‌ها.
- پایگاه دادهٔ SQLite با اجرای خودکار فایل‌های مهاجرت هنگام شروع.

## نیازمندی‌ها و اجرای محلی

نیازمند Node.js نسخهٔ ۲۰ یا جدیدتر و npm است.

```sh
npm install
cp .env.example .env
```

مقادیر `.env` را تنظیم کنید. برای تولید دو راز مستقل در ترمینال می‌توانید اجرا کنید:

```sh
openssl rand -hex 32
openssl rand -hex 32
```

خروجی اول را در `SESSION_SECRET` بگذارید و برای `ENCRYPTION_KEY` یک خروجی جداگانهٔ ۶۴ نویسه‌ای قرار دهید. گذرواژهٔ مدیر را در `ADMIN_PASSWORD` وارد کنید (حداقل ۱۲ نویسه) و برای `ADMIN_USERNAME` یک نام ۳ تا ۶۴ نویسه‌ای شامل حروف لاتین، عدد، نقطه، زیرخط یا خط تیره انتخاب کنید.

```sh
npm start
```

`better-sqlite3` includes a native SQLite binding. If your npm version blocks dependency build scripts, approve its build script (`npm install-scripts approve better-sqlite3`) and run `npm rebuild better-sqlite3` before starting.

پنل روی `http://localhost:3000` در دسترس است. نام کاربری و گذرواژه همان مقادیر `.env` هستند. سرور در شروع، پایگاه داده را در مسیر `DATABASE_PATH` می‌سازد و مهاجرت‌های موجود در `db/migrations/` را اعمال می‌کند.

## اتصال بات زنده

1. در بله با `@botfather` بات بسازید و توکن آن را از جای امن کپی کنید.
2. برای دریافت Update، سرور را با دامنهٔ عمومی HTTPS راه‌اندازی کنید و `APP_BASE_URL` را روی origin دامنه (برای نمونه `https://bots.example.com`) بگذارید. این مقدار مسیر، query یا fragment نمی‌گیرد. Bale برای webhook پورت خارجی ۴۴۳ یا ۸۸ را پشتیبانی می‌کند.
3. اگر برنامه پشت reverse proxy قرار دارد، HTTPS را در proxy فعال کنید و `TRUST_PROXY=1` را فقط وقتی بگذارید که proxy مورد اعتماد شما `X-Forwarded-*` را پاک‌سازی و بازنویسی می‌کند. پورت داخلی برنامه از `PORT` پیروی می‌کند.
4. در پنل، بات را اضافه کنید. برنامه ابتدا `getMe` را صدا می‌زند و سپس برای همان بات `setWebhook` را ثبت می‌کند.

اگر `APP_BASE_URL` تنظیم نشده باشد، می‌توانید بات را اضافه کنید اما Update دریافت نمی‌شود تا وب‌هوک روی یک نشانی HTTPS عمومی تنظیم شود. در صفحهٔ «ربات‌های من» پس از تنظیم متغیر محیطی، «تنظیم وب‌هوک» را بزنید.

## استقرار و نگهداری

- `.env` و `data/` را محرمانه نگه دارید. از هر دو نسخهٔ پشتیبان بگیرید؛ اگر `ENCRYPTION_KEY` گم شود، توکن‌های ذخیره‌شده قابل بازیابی نیستند.
- برای استقرار، Node.js و npm را روی سرور نصب کنید، کد را دریافت کنید، `.env` را بسازید، `npm install` و سپس `npm start` را اجرا کنید. برنامه را با process manager نگه دارید و reverse proxy را به `PORT` داخلی وصل کنید.
- دسترسی شبکه به برنامه را محدود کنید و برای دامنه گواهی TLS معتبر داشته باشید. مسیر وب‌هوک شامل راز تصادفی مجزا است؛ URL کامل فقط از نشست مدیر قابل مشاهده است.
- داده‌های Update بله تا ۲۴ ساعت و حداکثر ۲۰۰۰ پیام آخر در سمت بله نگهداری می‌شوند. این برنامه گزارش‌های محلی را تا وقتی بات حذف نشود نگه می‌دارد.
- اطلاعات پروفایل محدود به فیلدهایی است که Update بله ارائه می‌کند؛ شماره تماس و موقعیت کاربر فقط در صورت اشتراک‌گذاری کاربر در Update وجود دارند. ایمیل یا اطلاعات خصوصی دیگری از API قابل استخراج نیست.

## پوشش و محدودیت‌های API بله

این MVP از API رسمی `https://tapi.bale.ai/bot<TOKEN>/METHOD` و متدهای `getMe`، `setWebhook`، `deleteWebhook`، `sendMessage` و `answerCallbackQuery` استفاده می‌کند. جریان‌های این نسخه پیام متنی و منوهای ساده را پردازش می‌کنند؛ فایل، عکس، رسانه، پرداخت کیف‌پولی، ارسال انبوه، زمان‌بندی کمپین، فرم Mini App و مدیریت تنظیمات گروهی بات در این MVP پیاده‌سازی نشده‌اند.

مستندات بررسی‌شده: [مستندات رسمی بازوی بله](https://docs.bale.ai/). وب‌هوک با HTTPS POST در مستندات توصیف شده و در همان مستندات روش امضای رمزنگاری‌شدهٔ Update یا هدر راز وب‌هوک تعریف نشده است؛ برنامه از مسیر دارای راز تصادفی استفاده می‌کند، اما امضای payload را نمی‌تواند بررسی کند. callback با `answerCallbackQuery` پاسخ داده می‌شود؛ مستندات اشاره می‌کنند بعضی نسخه‌های قدیمی کلاینت بله این قابلیت را ندارند، برای همین خطای این پاسخ مانع اجرای جریان نمی‌شود.

متن «پذیرفته‌شده» در گزارش یعنی API بله درخواست `sendMessage` را پذیرفته و یک پیام برگشت داده است. Bot API این محصول رسید read یا delivery نهایی را گزارش نمی‌کند؛ بنابراین چنین وضعیتی در پنل ادعا نمی‌شود.

جریان‌ها فقط پیام‌های متنی خصوصی را اجرا می‌کنند. شرایط روی متن آخر کاربر بررسی می‌شوند و ورودی‌های ذخیره‌شده در متغیرهای همان پروفایل باقی می‌مانند. یک کاربر در هر بات هم‌زمان یک مسیر جاری دارد؛ اجرای `/start` مسیر قبلی را جایگزین می‌کند.
